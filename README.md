## 📚 Sobre o Repositório

Este repositório reúne atividades, exercícios e projetos desenvolvidos durante a disciplina de **Programação Web (PW)**.

O objetivo é registrar a evolução dos conhecimentos relacionados ao desenvolvimento de páginas e aplicações web, explorando conceitos de **HTML, CSS, JavaScript, estruturação de páginas, estilização, interatividade e boas práticas de desenvolvimento**.

## 🎯 Objetivos

* Desenvolver conhecimentos em Programação Web.
* Aprender a criar e estruturar páginas utilizando HTML.
* Aplicar estilos e layouts utilizando CSS.
* Desenvolver interatividade com JavaScript.
* Criar páginas responsivas e funcionais.
* Aplicar boas práticas de desenvolvimento web.
* Trabalhar em equipe em projetos acadêmicos.
* Utilizar Git e GitHub para versionamento e organização dos projetos.
